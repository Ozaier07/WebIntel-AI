## Quick Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the FastAPI server:
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```
3. Open `http://localhost:8000` (or the forwarded port `8000` in GitHub Codespaces).
